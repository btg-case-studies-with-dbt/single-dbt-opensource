## Launch Scope

This launch is a local architecture case-study release. It is not a production SaaS launch and must not be represented as real-customer ready.

## Go/No-Go Summary

| Area | Decision |
|---|---|
| Local doc review | Go after canonical docs are complete. |
| Local prototype inspection | Conditional go after ORR gates pass. |
| Production use | No-go. |
| Real customer data | No-go. |
| Customer evidence RAG | Not launched; architecture target only. |

## Product Readiness

- PR/FAQ, PRD, UID, TRD, detailed design, toolstack, metric dictionary, ORR, launch, and signoff docs exist.
- Supported domains are revenue, token usage, and quota/capacity.
- Customer-service and evidence RAG are future work.

## Operability Readiness

Required before local launch:

- `/health` checks process, MetricFlow, catalog freshness, and provider reachability.
- Structured request logs exist.
- Error categories are distinct.
- Runbook covers restart, catalog rebuild, LLM configuration, and eval execution.

## Communications Rules

Allowed claims:

- Local architecture case study.
- Synthetic data only.
- Governed MetricFlow execution.
- LLM does not generate SQL.
- Future RAG is for customer evidence retrieval, not analytics execution.

Not allowed:

- Production-ready.
- Real customer-data ready.
- Customer-service BI supported today.
- Root-cause agent shipped.
- ROI or productivity claims without measurement.
