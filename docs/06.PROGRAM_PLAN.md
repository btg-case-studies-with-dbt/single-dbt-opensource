## Critical Path

1. Lock canonical docs and checklist.
2. Implement five-category response contract.
3. Enforce metric and dimension validation server-side.
4. Fix provider and time-range defects.
5. Add structured logging and health checks.
6. Expand eval suite for routing and rejection categories.
7. Add customer evidence ingestion and retrieval design.
8. Add LangGraph agent loop after governed query path is stable.
