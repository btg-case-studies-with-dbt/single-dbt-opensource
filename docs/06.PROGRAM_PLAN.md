## Critical path

M1 → M2 → M4 → Close is the gating spine. **M3 (UI) and M5 (evidence) parallelize** off M2 — neither feeds the other, so they run concurrently, each clearing its own two-stage gate. The data model / catalog (M2) is the one-way door; nothing downstream of it parallelizes past it. Wall-clock is well under the summed hours because owners run in parallel.
