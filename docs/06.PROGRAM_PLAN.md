**PIVOT:** the ticket-RAG framing is RETIRED. Evidence is no longer a separate (fabricated) support-ticket corpus — it is a **governed decomposition of the metric movement itself** (which model/account/region drove it, the delta, coincident quota/revenue signals), produced by a **multi-step agentic loop** (`agent_graph.py`, dead code → request path). Root cause of the retirement: the C1/fixture tickets used fabricated FKs (`ACME-1234`) absent from `dim_customer` and described a different product — governing around fabrication instead of removing it. Evidence-from-governed-data removes the fabrication at the root.
**Done When:** agentic loop investigates a metric movement multi-step and returns a correct, non-fabricated evidence trace (contributing factors, correlation-not-causation), proven by a new multi-step eval; then Launch Go/No-Go + Human Sign-Off.
**SCOPE NOTE:** this is the largest increment in the program — a new reasoning architecture, a **one-way-door** change to the response contract (single metric → multi-step trace + evidence), and it reopens M1's contract + needs a NEW eval. **Design-first (MD before code); code stays behind the design gate-2.** Multi-session, not "close today."
