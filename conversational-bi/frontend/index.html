How it works

  1. Type a natural-language business question in the Ask tab.
  2. The backend routes it through an LLM to select a governed metric from the catalog.
  3. Your question is validated against the five-category contract and answered via MetricFlow.
  4. The outcome is displayed with category-specific styling.

Outcome Categories

  • answered (green) — MetricFlow returned a result (zero rows still counts as answered).
  • unknown_metric (blue) — The LLM proposed metrics not in the governed catalog.
  • ambiguous (blue) — The question matched multiple metrics; refine it.
  • unsupported_domain (amber) — The question is outside governed domains (Revenue, Token usage, Quota).
  • system_error (red) — Infrastructure failure (MetricFlow, LLM provider).
